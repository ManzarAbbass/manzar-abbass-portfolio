# Portfolio Selected Work Section Spec

## Overview

This is section 3 of 5 for the portfolio site layout. Use the screenshot referenced below for the alternating image/text row layout only. Project data must come from the mock data file referenced below — no invented metrics, ratings, or user counts.

## Requirements for work section

- Alternating two-column rows: project screenshot on one side, details on other side
- Per project: category label, project name + external link icon, 2-3 line real description, tech stack tags
- Badge overlay on screenshot only if there's a real, verifiable fact to show (e.g. "Live on Vercel", "Open source"). If no verifiable metric exists, omit the badge entirely rather than inventing one.
- Primary entry: DevStash — developer knowledge hub (Next.js 15, TypeScript, Prisma, Neon PostgreSQL, NextAuth v5, Stripe, Upstash Redis, Supabase Storage, OpenRouter API). Link to live demo and GitHub repo.
- Secondary entries (if included): Expense Tracker (React Context API), User Management Dashboard — framed as learning projects, not client work, since they aren't
- No category label implying a client engagement (e.g. "FINTECH STARTUP") for projects that were self-directed/course-based — use accurate labels (e.g. "PERSONAL PROJECT", "COURSE PROJECT")
