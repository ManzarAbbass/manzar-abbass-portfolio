# Portfolio Contact Section Spec

## Overview

This is section 5 of 5 for the portfolio site layout. Use the screenshot referenced below for form/layout reference only. Rates table and response-time promise from the reference should not be copied as-is — see requirements below.

## Requirements for contact section

- Two-column layout: left = intro text + contact info, right = contact form
- Contact info: real GitHub link, real email, no fixed "response time" promise unless able to consistently honor it around full-time work + study schedule
- Rates/pricing table: only include if actively quoting paid freelance work now. If not ready to quote real numbers, replace with a simpler "What I'm open to" list (e.g. small paid projects, collaboration, feedback) instead of a fixed-price table with invented figures
- Form fields: Name, Email, Project/Message details (Budget Range field optional — only include if rates section is also included)
- Submit button: solid accent-color fill, consistent with rest of site's CTA styling
