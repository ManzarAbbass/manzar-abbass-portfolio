# Portfolio Services Section Spec

## Overview

This is section 2 of 5 for the portfolio site layout. Use the screenshot referenced below for grid/card layout reference only. Content must reflect actual current capability, not a generic freelancer template's service list.

## Requirements for services section

- 2x2 (or fewer) grid of capability cards, index number + title + description + checklist bullets, matching bordered-cell style from reference
- Card count and titles must map to real, deliverable skills only — candidates:
  - Full-Stack Web Applications (Next.js, TypeScript, Prisma, PostgreSQL/Neon)
  - Authentication & Payments Integration (NextAuth, Stripe)
  - AI-Integrated Features (OpenRouter API — tag generation, code explanation, content optimization)
  - Technical Learning / Code Review (only if comfortable presenting this credibly at current experience level)
- Do NOT include: Mobile Development, Go backend, App Store submission, or any stack/skill not actually used in a shipped project
- Checklist bullets under each card should map to specific tools/patterns actually used in DevStash (e.g. "Prisma + Neon PostgreSQL", "Stripe webhooks", "Upstash Redis rate limiting")
