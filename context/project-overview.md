# Portfolio — Project Overview

> A personal freelance portfolio website for Manzar Abbass,
> a Full Stack Developer specialising in web apps and SaaS tools.
> Stack: Next.js 16 · React 19 · TypeScript · Tailwind CSS v4 · Framer Motion · Vercel

---

## Purpose

Showcase Manzar's development skills and projects to potential
freelance clients. The portfolio acts as a professional landing
page that converts visitors into clients.

---

## Target Visitors

| Visitor | Core Need |
|---|---|
| Startup Founder | Wants an MVP built fast and clean |
| Indie Maker | Needs a SaaS tool or web app |
| Small Team | Looking for a reliable dev for ongoing work |
