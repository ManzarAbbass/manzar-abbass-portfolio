# Section: Selected Work

## Layout
- Header: index "02" + "Selected Work" serif heading, horizontal rule.
- Alternating two-column project rows: image/screenshot on one side, text details on other side, alternating left/right per project.
- Each project block bordered (hairline), full-bleed screenshot fills its half.
- Floating badge on screenshot (yellow highlight box, e.g. "8k users in 6 weeks", "4.8★ on App Store") positioned top-left over image.
- Index number badge (black box, white/yellow text, e.g. "01", "02") top-left corner of image, separate from the highlight badge.

## Content structure (per project)
- Category label (small, gray, uppercase, mono, e.g. "FINTECH STARTUP", "SPORTS TECH").
- Project name (large serif, white/yellow).
- External link icon next to name.
- 2-3 line description: what it does + a concrete result metric.
- Tech stack pills/tags below description (bordered rounded rectangles, mono font).

## Examples shown
1. Lumio — fintech dashboard, Next.js/Go/PostgreSQL/Plaid API, "8,000 users in 6 weeks".
2. Fieldr — sports team management app, "4.8★ on App Store".

## To adapt for own portfolio
- Replace with real projects: DevStash (developer knowledge hub — Next.js 15, Prisma, NextAuth, Stripe, OpenRouter), Expense Tracker, User Management Dashboard.
- Don't fabricate metrics (no fake user counts/ratings) — use real, verifiable facts (e.g. "Live on Vercel", "Open source, X stars" if true) or omit the badge entirely rather than invent numbers.
- Link to live demo (devstash.vercel.app) and repo (github.com/ManzarAbbass/devstash) via the external link icon.
