# Section: How It Works (Process)

## Layout
- Header: index "04" + serif heading "How it works", horizontal rule.
- 4-column grid, each column separated by vertical hairline divider (no card backgrounds — flat, minimal).
- Each column: yellow mono index number ("01"-"04"), bold white subheading, gray descriptive paragraph.

## Content structure
1. Discovery call — 30-min call, understand goals/constraints/timeline, no pitch.
2. Proposal & scope — written scope, fixed-price quote, realistic timeline, no hidden fees.
3. Weekly check-ins — short async updates every Friday.
4. Handoff & support — clean docs, full code ownership transferred, 30-day support included.

## Design notes
- Very flat/minimal — no icons, just numbers + text. Relies on typography hierarchy and whitespace, not decoration.
- Section cut off at bottom in screenshot — likely followed by another CTA banner (yellow-bordered box visible at very bottom edge).
