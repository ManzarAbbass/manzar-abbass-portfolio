# Section: Hero

## Layout
- Two-column split (desktop): left = illustration, right = text content.
- Left column: dark flat illustration (isometric character at laptop, glowing screen), sits on solid black/near-black background block.
- Right column: aligned left, generous vertical spacing, max-width ~600px.
- Nav bar above: logo initials (left), 4 nav links centered/right (SERVICES, WORK, PROCESS, CONTACT), CTA button top-right with border + arrow icon.

## Content structure
- Eyebrow line: "— FREELANCE SOFTWARE DEVELOPER · AVAILABLE NOW" (yellow, uppercase, monospace, small).
- H1: 3-line headline mixing weights/styles, e.g. "I build / *software* / that ships." (serif bold, italic on middle word for contrast).
- Subtext: 2-3 line description of specialty + working style (mono/sans, muted gray).
- Below fold (cut off in screenshot): availability badge, likely CTA buttons.

## Design notes
- Palette: black bg (#0a0a0a-ish), off-white text, yellow/amber accent (#e8d44d-ish), muted gray secondary text.
- Typography: serif display font for headline (bold + italic variant), monospace for nav/labels/eyebrow text, sans/mono for body copy.
- Button style: transparent bg, yellow border, yellow uppercase mono text, arrow icon (↗).
- Overall tone: minimal, technical, confident — dev-portfolio aesthetic, not corporate.

## To adapt for own portfolio
- Replace illustration with own visual or drop it for a simpler layout.
- Replace copy with own positioning (e.g. "self-taught engineer" angle instead of pure freelance pitch, unless freelance is the actual goal).
- Keep nav structure but adjust sections to match actual site (e.g. Projects, About, Contact).
