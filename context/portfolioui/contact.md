# Section: Start a Project (Contact)

## Layout
- Header: index "05" + serif heading "Start a project", horizontal rule.
- Two-column layout: left = intro text + contact info + rates table; right = contact form.
- Left column info rows: label (yellow, mono, uppercase) + value (white), e.g. Email, GitHub, Response time.
- Rates box: bordered container, yellow "TYPICAL RATES" label, 3 rows (label left, price right) with hairline dividers between rows.
- Right column form: labeled inputs stacked vertically (Name, Email, Budget Range dropdown, Project Details textarea), dark input backgrounds with subtle border, placeholder text in muted gray.
- Submit button: solid yellow fill, black bold uppercase text, full-width, arrow icon.

## Content structure
- Intro line: prompts visitor to describe project with enough detail for accurate proposal.
- Contact info: Email, GitHub link, Response time ("Within 24 hours").
- Rates: Fixed-price project (from $4,000), Hourly consulting ($150/hr), Monthly retainer (from $3,500/mo).
- Form fields: Your Name, Email Address, Budget Range (select), Project Details (textarea).

## Design notes
- Only section using a solid-fill (non-outline) button — signals primary action.
- Rates are real pricing anchors, not vague ("starting at" language reduces friction).

## To adapt for own portfolio
- Rates section only makes sense once positioned for freelance clients — as a portfolio-building-toward-freelance page today, consider replacing rates table with "what I'm currently available for" (e.g. small paid projects, open to feedback/collab) or omit until ready to actually quote real dollar figures.
- Contact info: use real GitHub (github.com/ManzarAbbass) and a real email; don't list "within 24 hours" unless able to consistently honor it alongside job + study schedule.
